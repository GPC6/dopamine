# DOPA Story Editor 사용 안내

이 폴더는 비주얼노벨 게임 `도파민때문에`의 스토리를 편집하고, 바로 테스트해 볼 수 있는 웹 편집기입니다.

프로그래밍을 잘 몰라도 에피소드, 대사, 선택지, 배경, 캐릭터 등장, 미니게임 이동을 화면에서 입력할 수 있게 만든 도구입니다.

## 접속 주소

편집기는 GitHub Pages에서 아래 주소로 사용할 수 있습니다.

https://gpc6.github.io/dopamine/

이 주소로 들어가면 브라우저에서 바로 스토리를 편집할 수 있습니다. 편집한 내용은 `테스트 적용` 버튼을 눌렀을 때 같은 브라우저의 저장소에 저장되고, 테스트용 게임 화면에서 바로 읽어옵니다.

즉, 기본 작업 흐름은 다음과 같습니다.

```text
https://gpc6.github.io/dopamine/ 접속
-> 본게임 스토리 또는 가져오기로 스토리 불러오기
-> 노드와 선택지 수정
-> 테스트 적용
-> 새 탭에서 게임 진행 확인
-> 필요하면 내보내기로 백업
```

## 시작하기

`index.html`을 브라우저에서 열면 편집기가 실행됩니다.

GitHub Pages에서는 위 주소가 편집기 페이지입니다.

상단 버튼의 역할은 다음과 같습니다.

| 버튼 | 역할 |
| --- | --- |
| `샘플` | 짧은 예시 스토리를 불러옵니다. |
| `본게임 스토리` | 본게임의 `story-data-excel.js`를 편집기에 불러옵니다. |
| `가져오기` | JSON 또는 `const EPISODES = ...` 형식의 스토리 데이터를 붙여넣어 불러옵니다. |
| `테스트 적용` | 현재 편집 중인 스토리를 저장하고 테스트용 게임을 새 탭에서 엽니다. |
| `내보내기` | 현재 스토리를 JSON 또는 `story-data.js` 형식으로 복사/저장합니다. |

## 기본 구조

스토리는 `에피소드`와 `노드`로 이루어집니다.

에피소드는 큰 장면 묶음입니다. 예를 들면 `EP1`, `EP2`, `TRUE_ENDING` 같은 단위입니다.

노드는 에피소드 안에 들어가는 개별 명령입니다. 대사 한 줄, 선택지 하나, 배경 변경, 캐릭터 등장, 다른 에피소드로 이동 같은 것이 모두 노드입니다.

편집기 왼쪽에는 에피소드 목록이 있고, 오른쪽에는 선택한 에피소드 안의 노드들이 순서대로 표시됩니다.

## 에피소드 편집

왼쪽 위 `+` 버튼을 누르면 새 에피소드가 추가됩니다.

오른쪽 위 `에피소드 ID` 입력칸에서 현재 에피소드 이름을 바꿀 수 있습니다. 이름을 바꾼 뒤 `ID 변경`을 누르면 적용됩니다.

에피소드 ID는 짧고 구분하기 쉽게 쓰는 것이 좋습니다.

예시:

```text
EP1
EP2
EP_MT
TRUE_ENDING
BAD_ENDING
```

## 노드 추가

오른쪽 상단의 노드 버튼을 눌러 현재 에피소드에 노드를 추가합니다.

| 노드 | 역할 |
| --- | --- |
| `대사` | 화자와 대사를 표시합니다. |
| `선택지` | 플레이어가 고르는 버튼들을 표시합니다. |
| `이동` | 다른 에피소드로 이동하거나 미니게임을 시작합니다. |
| `사운드` | BGM을 시작/정지하거나 효과음을 재생합니다. |
| `배경` | 화면 배경을 바꿉니다. |
| `등장` | 캐릭터를 화면에 등장시킵니다. |
| `퇴장` | 캐릭터를 화면에서 퇴장시킵니다. |
| `캐릭터 지우기` | 현재 화면의 모든 캐릭터를 지웁니다. |
| `배경 지우기` | 현재 배경을 지웁니다. |
| `장면 초기화` | 배경과 캐릭터를 모두 지웁니다. |
| `엔딩 체크` | 현재 수치에 따라 엔딩을 판정합니다. |

노드 오른쪽의 `↑`, `↓` 버튼으로 순서를 바꿀 수 있습니다. `⧉` 버튼은 같은 노드를 바로 아래에 복제하고, `x` 버튼은 노드를 삭제합니다.

노드 번호는 편집기가 자동으로 다시 붙입니다. 중간에 노드를 삽입하거나 순서를 바꿔도 번호는 `1, 2, 3...` 형태로 정리됩니다.

노드를 클릭하거나 노드 안의 입력칸을 수정하면 그 노드가 활성화됩니다. 위쪽 노드 추가 버튼을 누르면 새 노드는 현재 활성화된 노드 바로 아래에 추가됩니다. 활성화된 노드가 없으면 에피소드 맨 아래에 추가됩니다.

## 대사 노드

대사 노드는 가장 기본적인 노드입니다.

입력할 내용:

| 항목 | 설명 |
| --- | --- |
| `화자` | 말하는 사람 이름입니다. |
| `대사` | 화면에 표시될 문장입니다. |
| `수치 변화` | 대사가 지나간 뒤 도파민이나 호감도가 바뀌어야 할 때 입력합니다. |
| `실행 조건` | 필요할 때만 입력합니다. 조건이 맞을 때만 이 대사가 나옵니다. |

## 선택지 노드

선택지 노드는 질문과 여러 개의 선택 항목으로 구성됩니다.

선택 항목마다 입력할 수 있는 내용은 다음과 같습니다.

| 항목 | 설명 |
| --- | --- |
| `버튼 문구` | 플레이어에게 보이는 선택지 문장입니다. |
| `다음 노드 번호` | 선택 후 이동할 현재 에피소드 안의 노드 번호입니다. |
| `호감도 변화` | 선택 후 호감도가 얼마나 바뀌는지 입력합니다. |
| `도파민 변화` | 선택 후 도파민이 얼마나 바뀌는지 입력합니다. |
| `선택 효과음` | 선택 버튼을 누르는 순간 재생할 효과음이나 BGM 명령입니다. 필요할 때만 펼쳐서 입력합니다. |
| `선택 조건` | 조건이 맞을 때만 보이는 선택지를 만들 때 씁니다. |
| `선택 직후 추가 발화` | 선택한 직후에만 나오는 짧은 대사를 넣습니다. |

중요한 규칙이 하나 있습니다.

선택지는 에피소드를 직접 이동하지 않습니다. 선택지는 항상 `현재 에피소드 안의 노드 번호`만 고릅니다.

다른 에피소드로 가야 한다면, 선택지의 `다음 노드 번호`가 `이동 노드`를 가리키게 만들고, 그 이동 노드에서 에피소드를 바꿉니다.

예시 흐름:

```text
#5 선택지
  선택 A -> #6
  선택 B -> #7

#6 선택 A 직후 공통 대사
#7 선택 B 직후 공통 대사
#8 이동 노드 -> EP2
```

여러 선택지가 다시 같은 흐름으로 합쳐진다면, 둘 다 같은 `다음 노드 번호`를 가리키게 하면 됩니다.

## 선택 직후 추가 발화

PDF 시나리오에서 선택지 아래에 `ㄴ`처럼 붙어 있던 문장은 선택지 버튼 문구가 아니라, 선택한 직후 이어지는 발화입니다.

이런 문장은 선택 항목 안의 `선택 직후 추가 발화`에 넣으면 됩니다.

추가 발화에도 `수치 변화`와 `발화 효과음`을 넣을 수 있습니다. 수치 변화는 해당 추가 발화가 지나갈 때 적용되고, 발화 효과음은 그 발화가 시작될 때 재생됩니다.

예시:

```text
버튼 문구: 여기 앉아도 돼
선택 직후 추가 발화:
  수진: 응?
  주인공: 아, 나는 건축학과 000이야.
다음 노드 번호: 12
```

실행 순서는 다음과 같습니다.

```text
선택지를 누름
-> 선택 직후 추가 발화가 먼저 나옴
-> 다음 노드 번호로 이동
```

## 이동 노드

이동 노드는 스토리 흐름을 바꾸는 노드입니다.

다른 에피소드로 이동하려면 `다음 에피소드`에 이동할 에피소드 ID를 입력합니다.

예시:

```text
다음 에피소드: EP3
```

특정 에피소드의 특정 노드로 이동하고 싶다면 `다음 노드 번호`도 함께 입력할 수 있습니다.

예시:

```text
다음 에피소드: EP3
다음 노드 번호: 5
```

미니게임으로 이동하려면 다음처럼 입력합니다.

```text
다음 에피소드: MINIGAME
미니게임: brickBreaker
미니게임 후 에피소드: EP4
```

미니게임마다 필요한 경우 `미니게임 옵션`을 펼쳐서 값을 입력할 수 있습니다.

| 항목 | 설명 |
| --- | --- |
| `최대 턴` | 턴 제한이 있는 미니게임에서 사용하는 값입니다. |
| `난이도` | 난이도 값을 받는 미니게임에서 사용하는 값입니다. |
| `진행 시간(초)` | 제한 시간이 있는 미니게임에서 사용하는 값입니다. |
| `최대 시간(초)` | 미니게임 코드가 이 이름을 쓰는 경우의 제한 시간입니다. |
| `최대 초` | 미니게임 코드가 이 이름을 쓰는 경우의 제한 시간입니다. |

`미니게임 튜토리얼`을 펼치면 미니게임 시작 전에 보여줄 안내 발화를 넣을 수 있습니다. `안내 화자`를 비워두면 기본 화자인 `파미니`가 사용됩니다.

사용 가능한 미니게임 ID:

| ID | 설명 |
| --- | --- |
| `brickBreaker` | 벽돌깨기 미니게임 |
| `sideShooter` | 슈팅 미니게임 |

## 사운드 노드

사운드 노드는 음악과 효과음을 제어합니다.

| 항목 | 설명 |
| --- | --- |
| `사운드 종류` | `bgm` 또는 `effect`를 고릅니다. |
| `동작` | `play`는 재생, `stop`은 정지입니다. |
| `사운드 이름` | 게임에 등록된 사운드 ID입니다. 목록에서 골라도 되고 직접 입력해도 됩니다. |
| `볼륨` | `0`부터 `1` 사이의 숫자입니다. |

BGM을 시작하려면 `사운드 종류`를 `bgm`, `동작`을 `play`로 둡니다.

BGM을 멈추려면 `사운드 종류`를 `bgm`, `동작`을 `stop`으로 둡니다.

효과음을 한 번 재생하려면 `사운드 종류`를 `effect`, `동작`을 `play`로 둡니다.

사운드 이름 추천 목록은 테스트 게임의 `config.js`에 등록된 `bgm`과 `effects`를 참고합니다. 실제 재생도 해당 파일에 등록된 사운드만 가능합니다.

## 배경과 캐릭터

배경 노드의 `배경 이름`에는 게임에 등록된 배경 이름을 입력합니다.

편집기에서는 현재 게임 시나리오와 `config.js`에 등록된 배경 이름이 추천 목록으로 표시됩니다. 목록에서 골라도 되고, 새 이름을 직접 입력해도 됩니다.

배경 노드의 `배경 전환`을 펼치면 배경이 바뀔 때의 효과를 지정할 수 있습니다.

| 항목 | 의미 |
| --- | --- |
| `전환 방식` | `fadeBlack`, `fadeSlide`, `none` 중 하나입니다. 비워두면 게임 기본값인 `fadeBlack`을 씁니다. |
| `전환 시간(ms)` | 전환 시간입니다. 게임에서는 120부터 2000 사이의 숫자를 사용합니다. |
| `슬라이드 방향` | `fadeSlide`에서 새 배경이 나타나는 방향입니다. `right` 또는 `left`를 씁니다. |
| `슬라이드 시간(ms)` | `fadeSlide`에서 새 배경이 열리는 시간입니다. 숫자가 클수록 천천히 열립니다. |

현재 기본 배경:

```text
dummy
```

캐릭터 등장 노드에는 `캐릭터 이름`과 `표정`을 입력합니다.

캐릭터 이름과 표정도 추천 목록에서 고를 수 있습니다. 추천 목록은 현재 전체 시나리오와 `config.js`의 캐릭터 자산을 참고해서 만들어집니다.

직접 입력도 가능합니다. 다만 실제 게임 화면에 이미지를 띄우려면 캐릭터 이름과 표정이 게임의 `config.js`에 등록된 이름과 맞아야 합니다.

## 실행 조건

각 노드와 선택 항목에는 조건을 걸 수 있습니다.

조건을 비워두면 항상 실행됩니다. 조건을 입력하면 그 조건을 만족할 때만 실행됩니다.

사용 가능한 조건:

| 조건 | 의미 |
| --- | --- |
| `도파민 최소` | 현재 도파민이 이 값 이상일 때만 실행 |
| `도파민 최대` | 현재 도파민이 이 값 이하일 때만 실행 |
| `호감도 최소` | 현재 호감도가 이 값 이상일 때만 실행 |
| `호감도 최대` | 현재 호감도가 이 값 이하일 때만 실행 |

예시:

```text
도파민 최소: 51
```

이렇게 입력하면 도파민이 51 이상일 때만 해당 노드나 선택지가 사용됩니다.

## 테스트 적용

편집 중인 스토리를 바로 게임에서 확인하려면 `테스트 적용`을 누릅니다.

그러면 현재 스토리가 브라우저 저장소에 저장되고, `gametest/index.html`이 새 탭에서 열립니다.

테스트 게임은 시작할 때 저장된 편집기 스토리를 먼저 읽습니다. 저장된 테스트 스토리가 없으면 본게임의 `story-data-excel.js`를 사용합니다.

GitHub Pages에서는 편집기와 테스트 게임이 같은 사이트 안에 있으므로 이 방식이 그대로 작동합니다.

## 내보내기

`내보내기` 버튼을 누르면 두 가지 형식 중 하나를 고를 수 있습니다.

| 형식 | 용도 |
| --- | --- |
| `JSON` | 편집기에서 다시 가져오기 쉬운 순수 데이터 형식입니다. |
| `story-data.js` | 게임 엔진에 바로 넣을 수 있는 형식입니다. |

작업을 오래 할 때는 중간중간 내보내기로 백업해 두는 것이 좋습니다.

## 작업할 때 기억할 규칙

선택지는 에피소드로 직접 이동하지 않습니다.

에피소드 이동과 미니게임 시작은 반드시 `이동` 노드에서 처리합니다.

선택지 뒤에 공통 대사가 이어진다면 별도 에피소드를 만들 필요 없이, 같은 에피소드 안의 공통 노드 번호를 가리키게 하면 됩니다.

노드 번호는 자동으로 다시 붙으므로 직접 고칠 필요가 없습니다.

캐릭터 이름, 배경 이름, 미니게임 ID는 게임에 등록된 이름과 정확히 같아야 합니다.
